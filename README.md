# UI-UX-Experiment5
## Aim:

To identify user problems, apply suitable UX research methods, and create user personas for different application scenarios to improve user experience.

## Algorithm:
```
1. Select two UX project scenarios for analysis.
2. Identify the target users and understand their problems.
3. List the major pain points faced by users in each scenario.
4. Write UX problem statements using the format:
“[User] needs a way to [achieve goal] because [obstacle], which results in [impact].”
5. Choose suitable UX research methods such as surveys, interviews, usability testing, and diary studies.
6. Justify why each research method is appropriate for the project.
7. Collect user behavior information based on assumptions or existing user scenarios.
8. Create at least two personas for each project scenario.
9. Include demographics, goals, behaviors, pain points, and motivations in each persona.
10. Prepare the final UX report document.
```
